# UniKit brand assets

워드마크는 사이트 디스플레이 폰트와 같은 **Syne Bold**(SIL OFL 1.1 — BI/로고 사용 가능).
마크는 Syne 비율을 닮은 커스텀 **U**(오른쪽 끝이 더 올라가고, 끝은 살짝 바깥으로)라 평평한 글자 U보다 표정이 있어요.
부제: **Public Sans**(OFL).

| `banner-readme.png` | README 배너 (1280×720) |
