- 기준 리비전: `ee37765` · 보존 대상 미커밋: `docs/sdd/40-requirements.md`(사이클 40, 본 사이클 범위 밖 — 수정·삭제 금지)

## 목표

방문자가 UniKit이 **무엇인지·왜 쓰는지·실제로 어떻게 보이는지**를 한 사이트에서 이해하게 한다. 소개(랜딩)와 **실제 UniKit 컴포넌트로 구성된 인터랙티브 쇼케이스/사용 예시**를 분리해 제공하고, 시각·카피는 AI 슬롭(범용 그라데이션 히어로·카드 나열·통계 칩·이모지·보라/크림 클리셰)을 피한 제품 고유 구성을 따른다.

## 범위

### 포함

1. **소개 랜딩 (`/`)** — 브랜드 우선 1뷰포트 히어로, 핵심 가치 1절, **라이브 사용 예시**(실제 `@unikit-bridge/ui` 컴포넌트 렌더), 설치 경로 안내, 전체 쇼케이스 진입 CTA.
2. **쇼케이스 (`/showcase`)** — 기존 `apps/web` `/` 컴포넌트 카탈로그 데모를 이전·유지. Expo 쇼케이스와의 “같은 섹션·문구” 계약은 쇼케이스 본문에 한정해 유지(랜딩은 웹 전용 마케팅 표면).
3. **레지스트리 `/r/*` 무손상** — shadcn 소비 경로·페이로드 동작 보존.
4. **디자인 기준 문서화** — G1에서 시각 방향·정보 구조·상태·접근성·반(anti)-슬롭 체크리스트를 확정하고 G4에서 실화면으로 검증.
5. **문서 정합** — README 빠른시작의 웹 URL 안내를 랜딩(`/`)·쇼케이스(`/showcase`)에 맞게 갱신.

### 제외

- 새 `apps/*` 앱 신설(레지스트리·배포 이중화 회피 — `apps/web` 확장으로 결정).
- Expo 앱에 랜딩 이식(네이티브 마케팅 페이지 불필요).
- npm 재게시·커밋·푸시·공개 호스팅(사용자 요청 시에만).
- 사이클 40(잔여 33종 이식) 구현.
- 신규 UI 컴포넌트 추가·토큰 값 변경(기존 28종·generate 마커 블록 보존).
- framer-motion 등 대형 모션 라이브러리 필수화(CSS/`@keyframes`·소량 전환으로 충분하면 그것 우선).

## 수락 조건 (AC-*)

| ID | 관찰 가능한 조건 |
|---|---|
| AC-1 | `http://localhost:3000/`(또는 `next start` 동일 경로)에서 UniKit **소개 랜딩**이 로드된다. 첫 뷰포트에 브랜드명 `UniKit`이 히어로급으로 존재하고, 한 줄 헤드라인·짧은 지지 문장·CTA 그룹(그중 **하나 이상은 `/showcase`로 이동**)·제품 시각(라이브 컴포넌트 스테이지)이 있다. |
| AC-2 | 랜딩에 **실제 사용 예시**가 있다: 사용자가 조작 가능한 UniKit 컴포넌트(최소 Button·Input·Card 또는 동등 조합 1세트 이상)가 렌더되며, 정적 목업 이미지만으로 대체하지 않는다. |
| AC-3 | `/showcase`에서 기존 웹 쇼케이스(28종 카탈로그 데모·테마 토글)가 동작한다. `/r/button.json`·`/r/registry.json`이 200으로 규격 페이로드를 반환한다. |
| AC-4 | **반-슬롭·사용성(G0 고정 관찰선, G4 실화면 판정):** (a) 히어로에 통계 칩·플로팅 뱃지·이모지 장식·카드 그리드가 없다. (b) 보라→인디고 그라데이션 테마·크림 배경+테라코타 악센트·브로드시트(헤어라인·다단 신문형) 클리셰가 없다. (c) 뷰포트 390·1280에서 본문 잘림·가로 스크롤·겹침이 없다. (d) 주요 CTA·테마 토글·라이브 예시 컨트롤이 키보드 포커스 가능하고 포커스 링이 보인다. G1은 이 선을 정교화하고, G4가 실화면으로 최종 판정한다. |
| AC-5 | 랜딩에 **핵심 가치 절 1개**(한 import·양 플랫폼 또는 동등 한 문장)와 **설치/소비 경로 안내**(npm 패키지 또는 shadcn `/r` 중 README와 일치하는 최소 1경로)가 본문에 존재한다. |
| AC-6 | `bun run typecheck`(루트 3패키지)·`apps/web` `bun run build`·`bun run audit:design`이 exit 0. |
| AC-7 | README 빠른시작이 랜딩(`/`)과 쇼케이스(`/showcase`) URL을 정확히 안내하고, 사이클 40 요구 파일(`docs/sdd/40-requirements.md`)은 본 사이클로 인해 변경되지 않는다. |

## 제약

- 패키지 매니저 bun. 워크스페이스·CI 스크립트 계약 유지.
- `globals.css`의 `generate:design` 마커 블록은 수동 편집 금지(마케팅 전용 스타일은 마커 밖 또는 별도 CSS 모듈/파일).
- 기존 Expo ↔ Web 쇼케이스 미러 본문 변경 시 양측 동시 유지. 본 사이클에서 쇼케이스는 **경로 이동·내비 링크 추가** 수준으로 한정하고 섹션 카피 대량 개편은 하지 않는다(필요 최소 수정만).
- 사용자 프론트엔드 디자인 규칙(히어로 예산·카드 남용 금지·폰트·배경·금기 클리셰) 준수.
