# 스마트폰에서 실물로 확인하기 (Expo Go 가이드)

UniKit의 자동 검증은 **웹 렌더링**(Expo web 내보내기·Next.js 빌드)과 **네이티브 번들 빌드**까지만 가능해요. 이 개발 환경에는 네이티브 에뮬레이터·실기기가 없어서, 실물 기기에서의 화면·테마 전환·눌림 감촉은 자동 검증 범위 밖이에요. 이 가이드는 그 확인을 **내 스마트폰의 Expo Go 앱**으로 직접 하는 방법이에요.

## 준비물

- 스마트폰과 컴퓨터가 **같은 Wi-Fi 네트워크**에 있을 것 (Expo Go가 컴퓨터의 개발 서버에 접속해요)
- 스마트폰에 **Expo Go 앱** 설치 — App Store(iOS) / Google Play(Android)에서 "Expo Go"를 검색해서 설치하세요. 이 프로젝트는 Expo SDK 58을 써요(`apps/expo/package.json` 참고).

## 실행 절차

컴퓨터에서 UniKit 저장소의 Expo 앱 폴더로 이동해 개발 서버를 띄워요:

```bash
cd apps/expo && bun x expo start
```

잠시 기다리면 Metro 개발 서버가 뜨고(`Waiting on http://localhost:8081` 안내가 나와요) 터미널에 QR 코드가 표시돼요.

스마트폰에서:

1. **Android** — Expo Go 앱을 열고 "Scan QR code"로 터미널의 QR을 스캔해요.
2. **iOS** — 카메라 앱으로 QR을 스캔하면 Expo Go로 열려요.

QR이 잘 안 되면, Expo Go 앱 안에서 터미널에 안내된 주소를 직접 입력하는 방법도 있어요.

번들이 기기로 전송되어 조금 뒤 쇼케이스 화면이 떠요. 서버는 컴퓨터에서 `Ctrl+C`로 종료해요(종료하면 기기에서도 앱이 닫혀요).

## 무엇을 확인하나요

쇼케이스 화면에서 이런 것들을 직접 확인해 보세요. 웹 검증으로는 닿지 않는 부분이에요:

- **Button** — 손끼림(press) 감촉과 눌림 색 변화. 눌린 쪽 손가락에서만 반응하는지, `disabled` 버튼은 아무리 눌러도 반응하지 않는지.
- **Input** — 소프트키보드가 올라오는 것, 포커스 시 테두리 강조. 라벨("이름"·"이메일")을 탭하면 대응 입력창에 포커스가 가는지.
- **라이트/다크 토글** — 오른쪽 위 버튼("🌙 다크")을 눌렀을 때 네이티브 런타임에서 전체 색이 즉시 전환되는지(왕복으로 몇 번 눌러 보세요).
- **SafeArea** — 기기 노치·홈 인디케이터 영역에 콘텐츠가 겹치지 않는지.
- **전체 외형** — 브라우저에서 본 화면(웹 검증 스크린샷)과 같은 모습인지.

## 자주 겪는 상황

- **연결이 안 돼요** — 스마트폰과 컴퓨터가 같은 Wi-Fi인지 확인하세요. 공용 Wi-Fi는 기기 간 접속을 막는 경우가 있어요.
- **포트가 이미 사용 중이에요** — Metro는 8081 포트를 써요. 다른 서버(예: UniKit 웹 번들 serve)가 떠 있으면 먼저 종료하세요. UniKit의 정적 웹 확인(`bunx serve apps/expo/dist -l 8081`)도 같은 포트를 쓰니 둘은 동시에 띄우지 마세요.
- **코드를 고쳤는데 반영이 안 돼요** — 개발 서버가 켜져 있는 동안은 저장하면 기기에 바로 반영돼요. 반영이 이상하면 앱을 다시 열어 보세요.

## 한계 안내

- 실물 기기 확인은 어디까지나 **사용자 직접 확인 절차**예요. 이 저장소의 자동 검증(AC 항목들)에는 포함되지 않아요.
- Expo Go는 개발용 앱이라 이 상태로는 앱스토어 배포가 되는 건 아니에요. 실제 배포는 후속 버전 과제예요(네이티브 빌드·publish는 v0.1 범위 밖).
